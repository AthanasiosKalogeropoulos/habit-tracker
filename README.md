# Habit Tracker

A habit tracker built with **React** and **TypeScript**.

> 🚧 **Work in progress.** This is a learning project, built step by step.

## Tech stack

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting started

```bash
# clone the repository
git clone https://github.com/AthanasiosKalogeropoulos/habit-tracker.git
cd habit-tracker

# install dependencies
npm install

# start the dev server
npm run dev
```

## Project structure

```
src/
├── components/   # HabitCard, HabitList
├── lib/          # types and mock data
├── App.tsx
└── main.tsx
```
